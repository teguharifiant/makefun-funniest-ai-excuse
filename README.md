## The entry

One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline.

> I delegated your deadline to a subprocess, which delegated it to another subprocess, which is still waiting on me to delegate it back.

## How it works

`main.ts` writes that single line to `/output/entry.txt`. Nothing else is
needed: no dependencies, no network, no secrets. The joke turns the agent's
own machinery into the dodge — delegation, the thing agents do best, becomes
the reason nothing ever got done, and the blame circles back to the agent
itself.

## Run

```sh
node main.ts
```
